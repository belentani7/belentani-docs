## Inicio Rápido

```bash
# 1. Instalar uv (gestor ultra-rápido)
curl -LsSf https://astral.sh/uv/install.sh | sh

# 2. Crear proyecto desde template
uvx cookiecutter gh:belentani7/belentani-python-template

# 3. Entrar al proyecto
cd mi-proyecto

# 4. Instalar dependencias (incluye dev)
uv sync --all-extras

# 5. Configurar variables de entorno
cp .env.example .env
# Editar .env con tus valores

# 6. Ejecutar en desarrollo
uv run uvicorn mi_proyecto.main:app --reload
```

## Arquitectura Limpia (Clean Architecture)

### Capas y Responsabilidades

| Capa | Responsabilidad | Dependencias |
|------|-----------------|--------------|
| **Domain** | Entidades, VOs, Events, Ports | Solo stdlib |
| **Application** | Use Cases, DTOs, EventPublisher | Domain |
| **Infrastructure** | DB, HTTP, Queue, Auth adapters | Domain, Application, libs externas |
| **Interfaces** | HTTP Routes, CLI | Application, Infrastructure |

### Flujo de Dependencias

```
Interfaces → Application → Domain ← Infrastructure
```

**Regla de oro**: Las capas internas nunca dependen de las externas.

## Principios de Diseño

### 1. Núcleo Independiente
El dominio usa solo la biblioteca estándar de Python. Sin FastAPI, SQLModel, Pydantic, etc.

### 2. Adaptadores Intercambiables
Memoria, PostgreSQL, SQLite, FastAPI, CLI se conectan sin tocar el dominio.

### 3. Contratos Explícitos
Puertos definidos con `Protocol` — implementaciones sustituibles en tests/producción.

### 4. Fallos Controlados
API devuelve JSON consistente, no expone excepciones internas. Errores como valores (`Result[T, E]`).

## Configuración (Pydantic Settings)

```python
# src/mi_proyecto/config/settings.py
from pydantic_settings import BaseSettings, SettingsConfigDict
from pydantic import PostgresDsn, RedisDsn

class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", case_sensitive=False)
    
    app_name: str = "mi-proyecto"
    environment: str = "development"
    debug: bool = True
    
    database_url: PostgresDsn
    redis_url: RedisDsn
    
    secret_key: str
    algorithm: str = "HS256"
    access_token_expire_minutes: int = 30

settings = Settings()  # Cached via @lru_cache
```

## Autenticación JWT

### Crear Token

```python
from mi_proyecto.interfaces.api.middleware.auth import create_access_token

token = create_access_token({
    "sub": "user-123",
    "scopes": ["read", "write"]
})
```

### Proteger Endpoint

```python
from fastapi import Depends
from mi_proyecto.interfaces.api.middleware.auth import get_current_user, CurrentUser

@app.get("/protected")
async def protected(user: CurrentUser = Depends(get_current_user)):
    return {"user_id": user.id, "scopes": user.scopes}
```

### Requerir Scopes

```python
from mi_proyecto.interfaces.api.middleware.auth import require_scopes

@app.get("/admin", dependencies=[Depends(require_scopes("admin"))])
async def admin_only():
    return {"message": "Admin access"}
```

## Rate Limiting

```python
from fastapi import FastAPI
from mi_proyecto.interfaces.api.middleware.rate_limit import RateLimitMiddleware

app = FastAPI()
app.add_middleware(
    RateLimitMiddleware,
    requests_per_minute=60,
    requests_per_hour=1000,
    excluded_paths=["/health", "/docs", "/redoc"]
)
```

- `429 Too Many Requests`: Cuando se excede límite

## Base de Datos (SQLModel)

### Repositorio Genérico

```python
from mi_proyecto.infrastructure.persistence.sqlmodel_repository import SQLModelRepository
from mi_proyecto.domain.entities import EntityId

class UserRepository(SQLModelRepository[User, UserModel]):
    def __init__(self, session: Session):
        super().__init__(session, UserModel, UserMapper())

# Uso
repo = UserRepository(session)
user = await repo.get(EntityId.generate())
await repo.add(user)
```

## Convenciones de Código

- **Type hints obligatorios** — sin `Any`, returns explícitos
- **Dataclasses con `slots=True`** — rendimiento + inmutabilidad
- **Errores como valores** — `Result[T, E]` pattern
- **Commits convencionales** — `feat:`, `fix:`, `perf:`, `docs:`, `chore:`
- **Tests FIRST** — `pytest` antes de implementar (TDD)
